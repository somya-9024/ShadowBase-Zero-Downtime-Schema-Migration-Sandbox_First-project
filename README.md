Week 1 – Day 1: Tools and Technologies Used

Backend Technology: Spring Boot (Java) is used to develop the backend application and manage server-side operations. Java provides the core programming logic for handling database-related tasks.

Frontend Technology: React.js is used to build the user interface, while Monaco Editor provides an IDE-like code editor for writing and editing SQL migration scripts.

Database and Containerization: Docker is used to manage containerized database environments, and Testcontainers is used to programmatically create and manage temporary PostgreSQL/MySQL database instances for testing.

Development Tools: Maven is used for dependency management and project building. Git and GitHub are used for version control and tracking project development.
