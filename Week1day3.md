## Week 1 - Day 3: Database Design and Schema Migration

**Database Design:** Studied the database structure and understood how tables, columns, primary keys, and foreign keys are organized.
                     Explored how different entities are connected to maintain proper data relationships.

**Schema Migration:** Learned about database schema migration and its importance in managing database structure changes. 
                      Understood how migration scripts help to add, modify, or update database tables and columns safely.

**Backend Integration:** Explored the role of Spring Boot in connecting the backend application with the database.
                         Understood how backend components interact with database operations and manage application data.
