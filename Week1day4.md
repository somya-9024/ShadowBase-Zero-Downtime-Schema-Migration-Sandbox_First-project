## Week 1 - Day 4: Backend Development and API Basics

**Backend Development:** Explored the backend project structure and understood the role of different packages, classes,
                         and components in a Spring Boot application. Learned how different layers work together to handle
                         application logic and data processing.

**REST API:** Learned the basics of REST APIs and understood how HTTP methods like GET, POST, PUT, and DELETE are used 
              to perform different operations. Explored how APIs help frontend and backend applications communicate with each other.

**Application Flow:** Studied how requests are received by the controller, processed by the service layer, and connected 
                      with the repository and database. Understood the overall flow of data within a Spring Boot application.
